# Contributing

1. Set up: [`docs/ai/onboarding.md`](docs/ai/onboarding.md).
2. Branch from `main` (`feat/…`, `fix/…`, `docs/…`, `chore/…`). `main` is protected; every change lands through a PR.
3. Follow the loop in [`docs/ai/workflow.md`](docs/ai/workflow.md): spec → plan → thin slices with tests → verify → review.
4. Keep PRs small (≤ ~400 changed lines, excluding docs and lockfile). Fill in the PR template with real verification output.
5. AI-assisted work follows [`docs/ai/policy.md`](docs/ai/policy.md): `Co-Authored-By` trailers, the `ai-assisted` label, and a human review of every line.
