# Plans

Implementation plans for multi-step work, written before coding (skill `feature-development`, `docs/ai/workflow.md`). One file per plan: `YYYY-MM-DD-<topic>.md`, 5–10 tasks, each ≤ half a day, each with its own verify command. Implement a plan in a fresh session. A milestone plan run by an orchestrator session (`docs/ai/workflow.md` §Orchestrated work) may list more tasks, each still ≤ half a day and one PR.
