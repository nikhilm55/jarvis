# Spikes

M0 feasibility spikes (FRS §11), one card per spike: `<id>.md`, plus optional `<id>.data.csv`. Follow the `spike` skill: hypothesis, method, pass bar and time-box first; then the result with real numbers, and a go/no-go decision. Throwaway spike code lives in `spikes/<id>/` at the repo root and is never imported by `src/`.
